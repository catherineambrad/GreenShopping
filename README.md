# 🛒 Greenshop

Custom WordPress eCommerce theme built with WooCommerce and Tailwind CSS.  
This project is a personal development project and is currently a work in progress.



## 📌 About

Greenshop is a custom WordPress theme developed from scratch with WooCommerce integration.

The project was created to practice:

- WordPress theme development
- WooCommerce customization
- PHP templating
- Tailwind CSS workflow
- Custom theme structure and modularization

⚠️ The theme is not fully completed and is used for learning and portfolio purposes.



## 🛠️ Tech Stack

- WordPress
- WooCommerce
- PHP
- Tailwind CSS
- JavaScript
- ACF (Advanced Custom Fields)



## ⚙️ Development

Tailwind build command:

```bash
npx tailwindcss -i ./assets/css/input.css -o ./assets/css/output.css --watch
```
